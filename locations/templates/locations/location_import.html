Import Guidelines

  • Use the exact column names shown above.
  • Country, state and city names should match existing records.
  • Latitude must be between -90 and 90.
  • Longitude must be between -180 and 180.
  • Do not leave address or coordinate fields empty.
  • Save the file as CSV UTF-8 before uploading.

Important

Please verify your CSV data before importing. Incorrect coordinates or location hierarchy can affect pickup, drop, distance and routing functionality.
